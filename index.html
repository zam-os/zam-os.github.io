Start for free

Install the Desktop or Mobile app and import content in minutes.

By default, ZAM opens in Free mode: a calm studio on your computer or Android phone where every free deck and FSRS-6 review works without AI setup.

1. Install the App

ZAM Desktop Studio & Mobile

Download the native Desktop app (macOS, Linux, Windows) or the Mobile app (Android) from GitHub Releases and follow the short free onboarding.

  • ZAM Desktop Studio — import decks, review offline, edit concepts and prerequisites, and explore your 3D Knowledge Atlas.
  • ZAM Mobile (Android) — lightweight daily active recall and free Academy cells wherever you go.
  • Quick terminal installer (optional) — curl -fsSL https://zam-os.org/install.sh | sh (or irm https://zam-os.org/install.ps1 | iex on Windows).

Download latest installers on GitHub Releases →

2. Import & Learn Free

Free courses, curricula & decks

Bring existing material or grab ready-made learning cells with one click — zero LLM calls required:

  • ZAM Academy — free interactive training apps paired with curated cards at academy.zam-os.org.
  • Open Library & Curricula — browse open-content collections and bundled curriculum topics straight inside the app.
  • Anki .apkg, CSV & TSV — import your existing flashcard decks and keep going with FSRS-6 scheduling.
  • Clean distraction-free recall — ready multiple-choice options when available, classic flashcard recall afterwards.

Works completely offline in one local SQLite database (~/.zam/zam.db).

Desktop · Advanced setup · Alpha

The Agentic Coding setup path Alpha

Learning directly from software work via /zam is the deepest setup path in ZAM Desktop. It stays hidden until you switch on AI mode and opt into Agentic Coding — and it requires a very capable frontier model.

  1. 1. Turn on “With AI” — switch from Free to With AI in Desktop Settings and complete the guided AI Setup Wizard with a frontier model.
  2. 2. Enable Agentic Coding (Alpha) — check the Agentic Coding option inside AI Settings; ZAM automatically installs the zam CLI on PATH and rolls out /zam and /okf skills into your configured workspaces.
  3. 3. Connect your coding agent over MCP — walk the Agentic Coding Alpha Wizard to link Claude Code, Codex, Antigravity, Copilot, OpenCode, Goose, or Hermes.
  4. 4. Work normally with /zam — open your agent in a configured workspace, type /zam on real tasks, and keep reviewing what matters in Desktop Studio or Mobile.
Model requirement (Alpha): Agentic Coding decomposes real tasks, tracks prerequisite gaps, and observes work unobtrusively. Use a highly capable model such as Claude Opus+, GPT 6.1 Sol+, or Gemini 4+ for reliable results.

How it works

A small, honest vocabulary.

token
One atomic concept worth remembering, tagged with a Bloom level (1 remember → 5 create).
card
Your personal spaced-repetition state for a token, scheduled by FSRS-6.
prerequisite
A graph of what must be understood first. ZAM won't quiz a concept whose foundations just slipped.
session
Every work-and-learning episode is logged, so ratings come from real evidence.

The learning engine is an AI-agnostic kernel with zero LLM dependencies — Free mode uses it directly offline, and optional AI or coding agents simply layer on top. Open source, Apache-2.0.
